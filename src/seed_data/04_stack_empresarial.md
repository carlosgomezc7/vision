# Stack Tecnológico y Arquitectura Empresarial

Las Intranets desarrolladas por CTI Soluciones siguen un estándar robusto y moderno:

## Stack Tecnológico Oficial
- **Frontend:** Next.js (App Router), Tailwind CSS, Shadcn UI para componentes limpios y accesibles.
- **Backend & Base de Datos:** Supabase (PostgreSQL) con soporte nativo para `pgvector`.
- **Autenticación:** Supabase Auth con integración OAuth/SAML para Microsoft 365 / Google Workspace.
- **Despliegue y CI/CD:** Vercel o servidores dedicados con contenedores Docker.

## Patrones de Código
- Modularidad estricta por dominios de negocio.
- Tipado estricto con TypeScript.
- Cobertura de pruebas en flujos críticos de autenticación y permisos (RBAC).
