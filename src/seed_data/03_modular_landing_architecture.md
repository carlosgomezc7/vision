# Modular Landing Page Architecture in Next.js

All landing pages generated by VISION follow a strict modular frontend architecture under the Next.js App Router:

```text
src/
├── app/
│   ├── layout.tsx         → Root HTML, fonts, global metadata, OpenGraph tags
│   ├── page.tsx           → Orchestrator importing sections in order
│   └── globals.css        → CSS Variables and Tailwind directives
├── components/
│   └── landing/
│       ├── Header.tsx     → Navigation and top CTA button
│       ├── Hero.tsx       → Headline, value proposition, and primary conversion button
│       ├── Services.tsx   → Core offerings with icons and clear descriptions
│       ├── About.tsx      → Client story and credibility indicators
│       ├── Testimonials.tsx → Social proof and customer reviews
│       ├── Contact.tsx    → Contact form, WhatsApp action, phone, and address
│       └── Footer.tsx     → Accessible footer with legal and quick links
```

Golden Rule: `page.tsx` never contains inline giant markup; it only renders decoupled section components. Zero server database or authentication overhead.
