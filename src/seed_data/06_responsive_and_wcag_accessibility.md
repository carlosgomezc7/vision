# Responsive Design and WCAG 2.2 AA Accessibility

Every landing page built by VISION must pass universal accessibility and responsiveness standards:

1. Contrast Standards:
   - Normal text (< 18pt or < 14pt bold): minimum 4.5:1 contrast.
   - Large text (>= 18pt or >= 14pt bold): minimum 3.0:1 contrast.
   - Rule: Never round up ratios (e.g. 4.49:1 is a FAIL).
2. Keyboard Navigability:
   - 100% operable via keyboard (Tab, Enter, Escape).
   - Explicit visible focus rings with high-contrast outlines.
3. Mobile First & Zoom:
   - 200% browser zoom without horizontal scroll bars or layout breaking.
   - Touch targets minimum 44x44px for thumb-friendly mobile browsing.
