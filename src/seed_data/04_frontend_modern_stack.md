# Modern Frontend Stack for Landing Pages

The production technology stack for VISION landing pages balances developer velocity, visual polish, and performance:

1. Framework: Next.js (App Router, Static Export ready).
2. Styling: Tailwind CSS (utility-first with CSS custom properties).
3. Component Library: `shadcn/ui` (accessible Radix primitives with copy-paste Tailwind code).
4. Icons: `lucide-react` (featherweight SVG icons).
5. Animations: CSS transitions and micro-interactions optimized to prevent main-thread blocking.
